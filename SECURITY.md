# Security

Found something? Don't open a public issue — [report it privately](https://github.com/romenkova/doska/security/advisories/new) from the Security tab.

This is a one-person project, so: I'll get back to you within a week. Give me a bit of time to ship a fix before going public, and I'll credit you in the advisory unless you'd rather I didn't.
